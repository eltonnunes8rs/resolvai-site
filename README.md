# ResolvAÍ — site (landing page)

Página estática publicada no GitHub Pages em https://resolvaioficial.com.br

- `index.html` — a página (tudo em um arquivo, CSS dentro).
- `site.js` — número do WhatsApp (`NUMERO`) e carregamento das avaliações.
- `avaliacoes.json` — avaliações reais. Vazio = a seção não aparece. Formato: `[{"nome":"Ana","cidade":"Francisco Beltrão","nota":5,"texto":"..."}]`
- `fonts/`, `img/`, `logo.svg`, `icone-*.png` — fontes e imagens (sem dependência externa).
- `CNAME` — domínio.

Antes de divulgar: confirmar o número do WhatsApp em `site.js`.
